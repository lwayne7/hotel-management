## 环境准备

### 必需软件

#### 1. Node.js（必装）
- **版本要求**：Node.js >= 18
- **下载地址**：https://nodejs.org/
- **推荐版本**：Node.js 18 LTS 或 20 LTS

**安装验证**：
```bash
node --version
npm --version
```

应该看到类似输出：
```
v18.x.x 或 v20.x.x
9.x.x 或更高
```

#### 2. 数据库选择（二选一）

本项目支持两种数据库：

**选项 A：SQLite（推荐新手使用）**
- ✅ 无需安装，开箱即用
- ✅ 零配置，适合学习和开发
- ✅ 数据存储在本地文件中
- ❌ 不适合生产环境
- ❌ 不支持多人协作

**选项 B：PostgreSQL（推荐团队协作）**
- ✅ 功能强大，适合生产
- ✅ 支持多人共享数据
- ✅ 更接近生产环境
- ❌ 需要安装和配置
- 下载地址：https://www.postgresql.org/download/

**本指南默认使用 PostgreSQL**（已配置完成）

## 后端启动

### 步骤 1：进入后端目录

```bash
cd hotel-management/backend
```

### 步骤 2：安装依赖

```bash
npm install
```

**说明**：这个命令会根据 `package.json` 安装所有需要的包，可能需要 2-5 分钟。

### 步骤 3：配置环境变量

创建 `.env` 文件：

```bash
copy .env.example .env
```

**`.env` 文件内容**（使用 PostgreSQL）：
```env
# Database - 使用 PostgreSQL
DB_TYPE=postgres
DB_HOST=localhost
DB_PORT=5432
DB_USERNAME=postgres
DB_PASSWORD=123456
DB_DATABASE=hotel_management

# JWT 密钥
JWT_SECRET=hotel_management_secret_key_2026
JWT_EXPIRES_IN=7d

# 服务器端口
PORT=3000
```

**重要说明**：
- `DB_TYPE=postgres`：使用 PostgreSQL 数据库
- `DB_PASSWORD`：你的 PostgreSQL 密码
- `JWT_SECRET`：用于加密用户登录令牌

**如果使用 SQLite**（可选）：
```env
DB_TYPE=sqlite
DB_DATABASE=hotel_management.sqlite
```

### 步骤 4：创建数据库（仅 PostgreSQL）

如果使用 PostgreSQL，需要先创建数据库：

```bash
# 运行创建数据库脚本
node create-postgres-db.js
```

**成功标志**：
```
✅ 成功连接到 PostgreSQL
✅ 数据库 hotel_management 创建成功！
```

**如果使用 SQLite**：跳过此步骤，会自动创建。

### 步骤 5：导入种子数据

导入测试数据（用户、酒店等）：

```bash
npm run seed
```

**成功标志**：
```
🎉 种子数据初始化完成！

📋 测试账号信息:
商户：merchant01 / Test123456
管理员：admin01 / Admin123456
```

### 步骤 6：启动后端服务

```bash
npm run start:dev
```

**成功标志**：看到以下输出表示启动成功
```
🚀 Server running on http://localhost:3000
📚 Swagger docs: http://localhost:3000/api/docs
```

**验证后端**：
- 打开浏览器访问：http://localhost:3000
- 应该看到：`{"message":"Welcome to Hotel Management API"}`
- 访问 API 文档：http://localhost:3000/api/docs

**注意**：保持这个终端窗口打开，后端服务需要一直运行！

## 常见问题

### Q1：后端启动失败，提示端口被占用

**错误信息**：`Error: listen EADDRINUSE: address already in use :::3000`

**解决方法**：
```bash
# Windows 查找占用端口的进程
netstat -ano | findstr :3000

# 结束进程（替换 PID 为实际进程号）
taskkill /PID <进程号> /F
```

### Q2：前端无法连接后端

**检查清单**：
1. 后端是否正常运行？访问 http://localhost:3000
2. 浏览器控制台是否有 CORS 错误？
3. 检查后端 `.env` 文件的 PORT 配置

### Q3：npm install 很慢

**解决方法**：使用国内镜像
```bash
npm config set registry https://registry.npmmirror.com
```

### Q4：数据库在哪里？

**PostgreSQL**：
- 数据存储在 PostgreSQL 服务器中
- 使用 pgAdmin 查看和管理
- 或使用命令行：`psql -U postgres -d hotel_management`

**SQLite**（如果使用）：
```
hotel-management/backend/hotel_management.sqlite
```

### Q5：如何重置数据库？

**PostgreSQL**：
```bash
# 重新导入种子数据
cd hotel-management/backend
npm run seed
```

**SQLite**：
```bash
# 删除数据库文件
del hotel_management.sqlite
npm run start:dev
npm run seed
```

### Q6：忘记密码怎么办？

直接在数据库中修改或删除用户重新注册。
