### 后端技术栈

#### 1. NestJS
**作用**：企业级 Node.js 框架

**核心概念**：
- **模块化**：将应用拆分成多个模块
- **依赖注入**：自动管理类的依赖关系
- **装饰器**：使用 @Controller、@Get 等装饰器

**基本结构**：
```typescript
// Controller - 控制器（处理 HTTP 请求）
@Controller('hotels')
export class HotelsController {
  constructor(private hotelsService: HotelsService) {}

  @Get()
  findAll() {
    return this.hotelsService.findAll();
  }

  @Post()
  create(@Body() createHotelDto: CreateHotelDto) {
    return this.hotelsService.create(createHotelDto);
  }
}

// Service - 服务层（业务逻辑）
@Injectable()
export class HotelsService {
  constructor(
    @InjectRepository(Hotel)
    private hotelRepository: Repository<Hotel>,
  ) {}

  async findAll() {
    return this.hotelRepository.find();
  }
}

// Module - 模块（组织代码）
@Module({
  imports: [TypeOrmModule.forFeature([Hotel])],
  controllers: [HotelsController],
  providers: [HotelsService],
})
export class HotelsModule {}
```

#### 3. Passport + JWT
**作用**：身份认证

**工作流程**：
```
1. 用户登录 → 验证用户名密码
2. 生成 JWT Token → 包含用户信息
3. 返回 Token 给前端 → 前端存储在 localStorage
4. 后续请求携带 Token → Header: Authorization: Bearer <token>
5. 后端验证 Token → 解析用户信息
6. 允许访问受保护的资源
```

**实现代码**：
```typescript
// JWT 策略
@Injectable()
export class JwtStrategy extends PassportStrategy(Strategy) {
  constructor() {
    super({
      jwtFromRequest: ExtractJwt.fromAuthHeaderAsBearerToken(),
      secretOrKey: process.env.JWT_SECRET,
    });
  }

  async validate(payload: any) {
    return { userId: payload.sub, username: payload.username };
  }
}

// 守卫 - 保护路由
@UseGuards(JwtAuthGuard)
@Get('profile')
getProfile(@Request() req) {
  return req.user; // 从 token 解析的用户信息
}
```

#### 5. store/slices/authSlice.ts - 认证状态
```typescript
import { createSlice, PayloadAction } from '@reduxjs/toolkit';

interface AuthState {
  user: User | null;
  token: string | null;
  isAuthenticated: boolean;
}

const initialState: AuthState = {
  user: null,
  token: localStorage.getItem('token'),
  isAuthenticated: !!localStorage.getItem('token'),
};

const authSlice = createSlice({
  name: 'auth',
  initialState,
  reducers: {
    setCredentials: (state, action: PayloadAction<{ user: User; token: string }>) => {
      state.user = action.payload.user;
      state.token = action.payload.token;
      state.isAuthenticated = true;
      localStorage.setItem('token', action.payload.token);
    },
    logout: (state) => {
      state.user = null;
      state.token = null;
      state.isAuthenticated = false;
      localStorage.removeItem('token');
    },
  },
});

export const { setCredentials, logout } = authSlice.actions;
export default authSlice.reducer;
```

#### 4. auth/auth.service.ts - 认证服务
```typescript
import { Injectable, UnauthorizedException } from '@nestjs/common';
import { JwtService } from '@nestjs/jwt';
import { UsersService } from '../users/users.service';
import * as bcrypt from 'bcrypt';

@Injectable()
export class AuthService {
  constructor(
    private usersService: UsersService,
    private jwtService: JwtService,
  ) {}

  // 注册
  async register(registerDto: RegisterDto) {
    // 密码加密
    const hashedPassword = await bcrypt.hash(registerDto.password, 10);
    
    // 创建用户
    const user = await this.usersService.create({
      ...registerDto,
      password: hashedPassword,
    });
    
    return { message: '注册成功', userId: user.id };
  }

  // 登录
  async login(loginDto: LoginDto) {
    // 查找用户
    const user = await this.usersService.findByUsername(loginDto.username);
    if (!user) {
      throw new UnauthorizedException('用户名或密码错误');
    }
    
    // 验证密码
    const isPasswordValid = await bcrypt.compare(loginDto.password, user.password);
    if (!isPasswordValid) {
      throw new UnauthorizedException('用户名或密码错误');
    }
    
    // 生成 JWT token
    const payload = { sub: user.id, username: user.username, role: user.role };
    const token = this.jwtService.sign(payload);
    
    return {
      access_token: token,
      user: {
        id: user.id,
        username: user.username,
        role: user.role,
      },
    };
  }
}
```

### 表结构详解

#### 1. users 表 - 用户表
```sql
CREATE TABLE users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  username VARCHAR(50) UNIQUE NOT NULL,
  password VARCHAR(255) NOT NULL,
  role VARCHAR(20) DEFAULT 'merchant',
  nickname VARCHAR(100),
  phone VARCHAR(20),
  createdAt DATETIME DEFAULT CURRENT_TIMESTAMP,
  updatedAt DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

**字段说明**：
- `id`: 主键，自增
- `username`: 用户名，唯一
- `password`: 密码（bcrypt 加密）
- `role`: 角色（merchant/admin）
- `createdAt/updatedAt`: 时间戳

#### 2. hotels 表 - 酒店表
```sql
CREATE TABLE hotels (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  nameCn VARCHAR(100) NOT NULL,
  nameEn VARCHAR(100),
  address VARCHAR(255) NOT NULL,
  starRating INTEGER NOT NULL,
  openingDate DATE,
  description TEXT,
  facilities TEXT, -- JSON 格式
  status VARCHAR(20) DEFAULT 'draft',
  rejectReason TEXT,
  merchantId INTEGER NOT NULL,
  createdAt DATETIME DEFAULT CURRENT_TIMESTAMP,
  updatedAt DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (merchantId) REFERENCES users(id)
);
```

**状态枚举**：
- `draft`: 草稿
- `pending`: 待审核
- `approved`: 已通过
- `rejected`: 已驳回
- `offline`: 已下线

#### 3. room_types 表 - 房型表
```sql
CREATE TABLE room_types (

  roomSize INTEGER,

```

#### 4. hotel_images 表 - 酒店图片表

```typescript
// auth/auth.service.ts
async register(registerDto: RegisterDto) {
  // 1. 检查用户名是否存在
  const existingUser = await this.usersService.findByUsername(registerDto.username);
  if (existingUser) {
    throw new ConflictException('用户名已存在');
  }
  
  // 2. 密码加密
  const hashedPassword = await bcrypt.hash(registerDto.password, 10);
  
  // 3. 创建用户
  const user = await this.usersService.create({
    ...registerDto,
    password: hashedPassword,
    role: 'merchant', // 默认商户角色
  });
  
  return { message: '注册成功', userId: user.id };
}
```

```typescript
// auth/auth.service.ts
async login(loginDto: LoginDto) {
  // 1. 查找用户
  const user = await this.usersService.findByUsername(loginDto.username);
  if (!user) {
    throw new UnauthorizedException('用户名或密码错误');
  }
  
  // 2. 验证密码
  const isPasswordValid = await bcrypt.compare(loginDto.password, user.password);
  if (!isPasswordValid) {
    throw new UnauthorizedException('用户名或密码错误');
  }
  
  // 3. 生成 JWT Token
  const payload = { 
    sub: user.id, 
    username: user.username, 
    role: user.role 
  };
  const token = this.jwtService.sign(payload, {
    secret: process.env.JWT_SECRET,
    expiresIn: '7d',
  });
  
  // 4. 返回结果
  return {
    access_token: token,
    user: {
      id: user.id,
      username: user.username,
      role: user.role,
      nickname: user.nickname,
    },
  };
}
```

### 4. 提交审核流程

**状态变更**：

```typescript
// hotels/hotels.service.ts
async submitForReview(id: number, userId: number) {
  // 1. 查找酒店
  const hotel = await this.hotelRepository.findOne({
    where: { id, merchant: { id: userId } },
    relations: ['roomTypes'],
  });
  
  if (!hotel) {
    throw new NotFoundException('酒店不存在');
  }
  
  // 2. 验证状态
  if (hotel.status !== 'draft' && hotel.status !== 'rejected') {
    throw new BadRequestException('只有草稿或已驳回的酒店可以提交审核');
  }
  
  // 3. 验证必填信息
  if (!hotel.roomTypes || hotel.roomTypes.length === 0) {
    throw new BadRequestException('至少需要添加一个房型');
  }
  
  // 4. 更新状态
  hotel.status = 'pending';
  hotel.rejectReason = null; // 清空驳回原因
  
  await this.hotelRepository.save(hotel);
  
  return { message: '提交审核成功' };
}
```

## 常见问题解答

### Q1: 什么是前后端分离？
前端和后端是两个独立的项目，通过 HTTP API 进行通信。前端负责展示界面，后端负责处理业务逻辑和数据存储。

### Q2: JWT Token 是什么？
JWT（JSON Web Token）是一种用于身份认证的令牌。用户登录后，服务器生成一个 Token 返回给前端，前端在后续请求中携带这个 Token，服务器验证 Token 来识别用户身份。

### Q3: Redux 是做什么的？
Redux 是一个状态管理工具，用于管理应用的全局状态。比如用户登录信息、购物车数据等需要在多个组件间共享的数据。

### Q4: TypeORM 是什么？
TypeORM 是一个 ORM（对象关系映射）工具，它让我们可以用 TypeScript 类来操作数据库，而不需要写 SQL 语句。

### Q5: 如何调试代码？
- 前端：使用浏览器开发者工具（F12）的 Console 和 Network 标签
- 后端：使用 console.log() 或 NestJS 的 Logger
- 数据库：使用 DB Browser for SQLite 查看数据
