### 2.3 创建环境配置文件

**操作**：复制 `.env.example` 为 `.env`

```bash
copy .env.example .env
```

**`.env` 文件内容**：
```env
# Database - 使用 SQLite（开发环境）
DB_TYPE=sqlite
DB_DATABASE=hotel_management.sqlite

# JWT 密钥
JWT_SECRET=hotel_management_secret_key_2026
JWT_EXPIRES_IN=7d

# 服务器端口
PORT=3000

# OSS (Aliyun) - 可选配置
OSS_REGION=oss-cn-hangzhou
OSS_ACCESS_KEY_ID=your_access_key_id
OSS_ACCESS_KEY_SECRET=your_access_key_secret
OSS_BUCKET=your_bucket_name
```

**配置说明**：
- 使用 SQLite 数据库，无需安装 PostgreSQL
- JWT_SECRET 设置为自定义密钥
- 端口使用默认的 3000

✅ **结论**：环境配置完成

## 常见问题处理

### 问题 1：端口被占用

**错误信息**：
```
Error: listen EADDRINUSE: address already in use :::3000
```

**解决方法**：
```bash
# Windows 查找占用端口的进程
netstat -ano | findstr :3000

# 结束进程（替换 PID 为实际进程号）
taskkill /PID <进程号> /F
```

### 问题 2：npm install 失败

**可能原因**：
- 网络问题
- npm 源速度慢

**解决方法**：
```bash
# 使用国内镜像
npm config set registry https://registry.npmmirror.com

# 重新安装
npm install
```

### 问题 3：前端无法连接后端

**检查清单**：
1. ✅ 后端是否正常运行？访问 http://localhost:3000
2. ✅ 浏览器控制台是否有错误？按 F12 查看
3. ✅ 后端 CORS 配置是否正确？
