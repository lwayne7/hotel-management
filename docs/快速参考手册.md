# 易宿酒店管理系统 - 快速参考手册

## 🚀 快速启动

### 启动后端
```bash
cd hotel-management/backend
npm run start:dev
```
访问：http://localhost:3000

### 启动前端
```bash
cd hotel-management/frontend
npm run dev
```
访问：http://localhost:5173

### 导入种子数据（首次运行）
```bash
cd hotel-management/backend
npm run seed
```

### 生成大量测试数据
```bash
cd hotel-management/backend
npm run generate-hotels  # 生成10000家酒店
```

### 清空酒店数据
```bash
cd hotel-management/backend
npm run clear-hotels
```

## 📡 API 接口速查

### 认证接口

#### 用户注册
```http
POST /auth/register
Content-Type: application/json

{
  "username": "user1",
  "password": "password123",
  "role": "merchant",
  "nickname": "测试用户"
}
```

#### 用户登录
```http
POST /auth/login
Content-Type: application/json

{
  "username": "user1",
  "password": "password123"
}

响应：
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": 1,
    "username": "user1",
    "role": "merchant"
  }
}
```

#### 获取当前用户信息
```http
GET /auth/profile
Authorization: Bearer <token>
```

---

### 商户接口

#### 获取我的酒店列表
```http
GET /hotels/my
Authorization: Bearer <token>
```

#### 创建酒店
```http
POST /hotels
Authorization: Bearer <token>
Content-Type: application/json

{
  "nameCn": "测试酒店",
  "address": "北京市朝阳区xxx路",
  "starRating": 5,
  "description": "酒店介绍",
  "roomTypes": [
    {
      "name": "豪华大床房",
      "price": 588,
      "maxGuests": 2
    }
  ]
}
```

#### 更新酒店
```http
PATCH /hotels/:id
Authorization: Bearer <token>
Content-Type: application/json

{
  "nameCn": "更新后的酒店名称",
  "address": "新地址"
}
```

#### 删除酒店
```http
DELETE /hotels/:id
Authorization: Bearer <token>
```

#### 提交审核
```http
POST /hotels/:id/submit
Authorization: Bearer <token>
```

---

### 管理员接口

#### 获取所有酒店
```http
GET /admin/hotels?status=pending
Authorization: Bearer <token>
```

#### 审核通过
```http
POST /admin/hotels/:id/approve
Authorization: Bearer <token>
```

#### 审核驳回
```http
POST /admin/hotels/:id/reject
Authorization: Bearer <token>
Content-Type: application/json

{
  "reason": "酒店信息不完整"
}
```

#### 酒店下线
```http
POST /admin/hotels/:id/offline
Authorization: Bearer <token>
```

#### 酒店上线
```http
POST /admin/hotels/:id/online
Authorization: Bearer <token>
```

## 🗄️ 数据库操作

### PostgreSQL 数据库

**查看数据库**：
使用 [pgAdmin](https://www.pgadmin.org/) 或命令行：
```bash
psql -U postgres -d hotel_management
```

### 常用 SQL 查询

#### 查看所有用户
```sql
SELECT * FROM users;
```

#### 修改用户角色为管理员
```sql
UPDATE users SET role = 'admin' WHERE username = 'merchant01';
```

#### 查看所有酒店
```sql
SELECT 
  h.id,
  h."nameCn",
  h.status,
  u.username as merchant
FROM hotels h
LEFT JOIN users u ON h."merchantId" = u.id;
```

#### 查看待审核的酒店
```sql
SELECT * FROM hotels WHERE status = 'pending';
```

#### 重置数据库
```bash
# 重新导入种子数据
cd hotel-management/backend
npm run seed
```

### SQLite 数据库（如果使用）

**查看数据库**：
使用 [DB Browser for SQLite](https://sqlitebrowser.org/) 打开：
```
hotel-management/backend/hotel_management.sqlite
```

#### 删除所有数据（重置数据库）
```sql
DELETE FROM hotel_images;
DELETE FROM room_types;
DELETE FROM hotels;
DELETE FROM users;
```

## 🔑 酒店状态说明

| 状态 | 英文 | 说明 | 可操作 |
|------|------|------|--------|
| 草稿 | draft | 新建或编辑中 | 编辑、删除、提交审核 |
| 待审核 | pending | 等待管理员审核 | 管理员：通过/驳回 |
| 已通过 | approved | 审核通过，已发布 | 管理员：下线 |
| 已驳回 | rejected | 审核未通过 | 编辑、提交审核 |
| 已下线 | offline | 管理员下线 | 管理员：上线 |
