## 🚀 快速开始

### 第一次运行项目？

1. **确保已安装 Node.js >= 18**
   ```bash
   node --version
   ```

2. **启动后端**
   ```bash
   cd hotel-management/backend
   npm install
   copy .env.example .env
   # 编辑 .env 配置 PostgreSQL
   node create-postgres-db.js
   npm run seed
   npm run start:dev
   ```

3. **启动前端（新终端）**
   ```bash
   cd hotel-management/frontend
   npm install
   npm run dev
   ```

4. **访问系统**
   - 前端：http://localhost:5173
   - 后端：http://localhost:3000
   - API 文档：http://localhost:3000/api/docs
   - 测试账号：merchant01 / Test123456

详细步骤请查看 [项目运行指南](./项目运行指南.md)

## 📖 项目概览

### 技术栈

**前端**：
- ⚛️ React 19 + TypeScript 5.9
- ⚡ Vite 7
- 🎨 Ant Design 6.x
- 🔄 Redux Toolkit
- 🛣️ React Router 7

**后端**：
- 🦅 NestJS + TypeScript
- 🗃️ TypeORM
- 🐘 PostgreSQL（生产环境配置）
- 🔐 Passport + JWT
- 🌱 种子数据支持

### 主要功能

**商户端**：
- ✅ 用户注册登录
- ✅ 酒店信息管理（增删改查）
- ✅ 房型管理
- ✅ 提交审核

**管理员端**：
- ✅ 酒店审核（通过/驳回）
- ✅ 酒店上下线管理
- ✅ 查看所有酒店

**测试数据**：
- ✅ 3个测试账号（2商户+1管理员）
- ✅ 20个精选演示酒店（覆盖多城市、多价位与多种标签）
- ✅ 完整的业务流程演示

## 💡 学习建议

### 对于前端三件套基础的学习者

1. **先运行起来**
   - 不要急于理解所有代码
   - 先把项目跑起来，看到效果
   - 建立信心

2. **从简单开始**
   - 先看前端页面组件
   - 理解 React 组件的结构
   - 学习如何使用 Ant Design

3. **逐步深入**
   - 理解路由如何工作
   - 学习状态管理（Redux）
   - 了解 API 调用（Axios）

4. **后端学习**
   - 理解 RESTful API 概念
   - 学习 NestJS 的模块化结构
   - 了解数据库操作

5. **实践为主**
   - 尝试修改页面样式
   - 添加新的表单字段
   - 实现新功能

### 推荐学习顺序

```
HTML/CSS/JavaScript 基础
    ↓
TypeScript 基础
    ↓
React 基础（组件、Props、State、Hooks）
    ↓
React Router（路由）
    ↓
Redux（状态管理）
    ↓
Ant Design（UI 组件）
    ↓
Axios（HTTP 请求）
    ↓
Node.js 基础
    ↓
NestJS 框架
    ↓
TypeORM（数据库操作）
    ↓
JWT 认证
```
