# 易宿酒店预订平台演示脚本（7-10分钟）

## 演示前准备（不计时）
- 启动后端：`hotel-management/backend` -> `npm run start:dev`
- 启动管理端：`hotel-management/frontend` -> `npm run dev`
- 启动移动端（H5）：`hotel-mobile-taro` -> `npm run dev:h5`
- 账号准备：
  - 商户：`merchant01 / Test123456`
  - 管理员：`admin01 / Admin123456`

## 0:00 - 0:40 项目开场
- 说明系统分两端：用户预订流程 + 商户/管理员管理流程。
- 点明演示目标：验证“新增酒店 -> 审核发布 -> 移动端可见”的完整闭环。

## 0:40 - 2:30 商户端录入与提审
1. 登录商户账号，进入“我的酒店”。
2. 点击“新增酒店”，填写关键字段：
   - 酒店中英文名、地址、星级、开业时间。
   - 至少一个房型并设置价格。
3. 点击“提交审核”，观察状态变更为“审核中”。
4. 说明规则：已发布/已下线酒店编辑后会自动进入待审核。

## 2:30 - 4:20 管理员审核与上下线
1. 退出商户，登录管理员账号，进入“酒店审核”。
2. 打开待审核记录，查看详情弹窗（基础信息、图片、房型）。
3. 执行“驳回”一次并填写原因，切到商户端列表展示驳回原因可见。
4. 再次提交后在管理员端“通过”，状态变为已发布。
5. 演示“下线”与“上线（恢复）”按钮，说明下线不是删除。

## 4:20 - 6:40 用户端三页联动
1. 打开移动端首页：
   - 展示 Banner、关键词、日期（日历组件）、快捷标签。
2. 进入列表页：
   - 调整筛选（价格/星级/综合），演示上滑自动加载。
   - 显示虚拟滚动启用提示（大数据量场景）。
3. 进入详情页：
   - 轮播图、基础信息、日期间夜、房型价格升序展示。
   - 点击分享入口：可复制分享文案（非占位提示）。

## 6:40 - 7:50 实时与性能说明
- 实时机制：
  - H5 使用 SSE 事件流（`type/timestamp/hotelId/changeKind/version`）。
  - 小程序/RN 轮询兜底，保证跨端稳定。
- 性能机制：
  - 列表虚拟滚动 + 分页加载；
  - 仅对受影响酒店做增量刷新（避免全量重拉）。

## 7:50 - 8:30 质量与文档收口
- 展示质量门禁结果摘要：
  - 前端 lint、构建通过；
  - 后端构建、测试通过；
  - 移动端 typecheck、测试通过。
- 展示答辩资料目录：`docs/defense/*`。

## 备用话术（时间不足时）
- 优先保留：商户提审 -> 管理员通过 -> 移动端可见 三步闭环。
- 压缩项：跳过驳回回放，仅口头说明驳回原因可见已实现。
