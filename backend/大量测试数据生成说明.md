## 🚀 使用方法

### 1. 确保数据库已启动

**PostgreSQL:**
```bash
# 检查 PostgreSQL 是否运行
pg_isready

# 如果未运行,启动 PostgreSQL
# Windows: 在服务中启动 PostgreSQL
# Mac: brew services start postgresql
# Linux: sudo systemctl start postgresql
```

**SQLite:**
```bash
# SQLite 无需启动服务,直接运行即可
```

### 2. 配置环境变量

确保 `.env` 或 `.env.local` 文件配置正确:

```env
# PostgreSQL 配置
DB_TYPE=postgres
DB_HOST=localhost
DB_PORT=5432
DB_USERNAME=postgres
DB_PASSWORD=your_password
DB_DATABASE=hotel_management

# 或 SQLite 配置
DB_TYPE=sqlite
DB_DATABASE=hotel_management.sqlite
```

### 3. 运行生成脚本

```bash
cd hotel-management/backend

# 生成 10,000 条数据
npm run seed:large
```

### 4. 预计耗时

- **PostgreSQL**: 约 5-10 分钟
- **SQLite**: 约 10-20 分钟

## ⚠️ 注意事项

### 1. 数据库空间
- PostgreSQL: 确保有至少 **500MB** 可用空间
- SQLite: 确保有至少 **1GB** 可用空间

### 2. 内存要求
- 建议至少 **4GB** 可用内存
- 批量处理避免内存溢出

### 3. 数据清理
如需重新生成,先清空数据库:

```sql
-- PostgreSQL
TRUNCATE TABLE hotel_image CASCADE;
TRUNCATE TABLE room_type CASCADE;
TRUNCATE TABLE hotel CASCADE;

-- SQLite
DELETE FROM hotel_image;
DELETE FROM room_type;
DELETE FROM hotel;
```

### 4. 性能优化
- 使用批量插入提高速度
- 关闭不必要的索引
- 生成完成后重建索引

## 📊 数据统计查询

生成完成后,可以运行以下查询验证数据:

```sql
-- 总酒店数
SELECT COUNT(*) FROM hotel;

-- 按城市统计
SELECT 
  SUBSTRING(address FROM 1 FOR 2) as city,
  COUNT(*) as count
FROM hotel
GROUP BY city
ORDER BY count DESC;

-- 按星级统计
SELECT star_rating, COUNT(*) as count
FROM hotel
GROUP BY star_rating
ORDER BY star_rating DESC;

-- 按状态统计
SELECT status, COUNT(*) as count
FROM hotel
GROUP BY status;

-- 价格分布
SELECT 
  CASE 
    WHEN price < 500 THEN '经济型'
    WHEN price < 1000 THEN '舒适型'
    WHEN price < 2000 THEN '高档型'
    ELSE '豪华型'
  END as price_range,
  COUNT(*) as count
FROM room_type
GROUP BY price_range;
```
