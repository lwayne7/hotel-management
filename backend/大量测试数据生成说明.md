# 大量测试数据生成说明

## 概述

本项目提供完整的种子数据系统,支持快速生成大量测试酒店数据,用于测试筛选、排序、分页等功能。

## 可用命令

### 1. 初始化基础数据

```bash
npm run seed
```

**功能**:
- 创建 3 个测试用户(2个商户 + 1个管理员)
- 创建 10 家精选演示酒店
- 包含完整的房型和图片数据

**适用场景**: 首次启动项目,快速体验功能

---

### 2. 批量生成测试酒店

```bash
npm run generate-hotels
```

**功能**:
- 生成 **10,000 家酒店**
- 数据分布均匀,确保筛选功能测试覆盖完整

**数据分布**:

| 维度 | 分布策略 | 数量 |
|------|---------|------|
| 亲子酒店 | 20% | ~2000 家 |
| 豪华酒店 | 20% | ~2000 家 |
| 免费停车场 | 20% | ~2000 家 |
| 含早餐 | 20% | ~2000 家 |
| 健身房 | 20% | ~2000 家 |
| 1星级 | 20% | ~2000 家 |
| 2星级 | 20% | ~2000 家 |
| 3星级 | 20% | ~2000 家 |
| 4星级 | 20% | ~2000 家 |
| 5星级 | 20% | ~2000 家 |
| 覆盖城市 | 均匀分布 | 50 个城市 |

**性能特点**:
- 使用事务批量写入(每批100家)
- 实时进度显示
- 平均速度: ~165 家/秒
- 总耗时: ~1 分钟

**适用场景**: 测试大数据量下的筛选、排序、分页功能

---

### 3. 清空酒店数据

```bash
npm run clear-hotels
```

**功能**:
- 删除所有酒店数据
- 删除所有房型数据
- 删除所有酒店图片数据
- 保留用户数据

**适用场景**: 重新导入种子数据前清空旧数据

---

### 4. 更新酒店图片

```bash
npm run update-images
```

**功能**:
- 将数据库中的酒店图片更新为精选 Unsplash 图片
- 150+ 张高质量酒店图片
- 使用种子算法确保不同酒店图片唯一

**图片分类**:
- 酒店外观: 50 张
- 酒店大堂: 20 张
- 游泳池: 15 张
- 大床房: 20 张
- 双床房: 15 张
- 套房: 15 张
- 家庭房: 12 张
- 标准间: 12 张

## 数据验证

### 验证数据分布

生成完成后,可以通过以下方式验证数据分布:

#### 1. 使用 pgAdmin 查询

```sql
-- 查看总数
SELECT COUNT(*) FROM hotels;

-- 查看星级分布
SELECT "starRating", COUNT(*) 
FROM hotels 
GROUP BY "starRating" 
ORDER BY "starRating";

-- 查看设施分布
SELECT 
  COUNT(CASE WHEN '亲子' = ANY(facilities) THEN 1 END) as 亲子,
  COUNT(CASE WHEN '豪华' = ANY(facilities) THEN 1 END) as 豪华,
  COUNT(CASE WHEN '免费停车场' = ANY(facilities) THEN 1 END) as 停车场,
  COUNT(CASE WHEN '含早餐' = ANY(facilities) THEN 1 END) as 早餐,
  COUNT(CASE WHEN '健身房' = ANY(facilities) THEN 1 END) as 健身房
FROM hotels;

-- 查看城市分布
SELECT city, COUNT(*) 
FROM hotels 
GROUP BY city 
ORDER BY COUNT(*) DESC 
LIMIT 10;
```

#### 2. 使用前端测试

1. 启动前端项目
2. 访问酒店列表页
3. 测试各种筛选条件:
   - 按星级筛选
   - 按设施筛选
   - 按城市筛选
   - 按价格区间筛选
4. 验证每个筛选条件都能返回合理数量的结果

## 技术实现

### 数据生成算法

```typescript
// 使用种子算法确保数据可重现
const seed = hotelIndex + cityIndex * 10000;

// 星级分布: 循环分配1-5星
const starRating = (hotelIndex % 5) + 1;

// 设施分布: 每个酒店分配一个主要标签
const facilityIndex = hotelIndex % 5;
const mainFacility = FACILITIES[facilityIndex];

// 价格分布: 基于星级和设施
const basePrice = 200 + starRating * 100;
const price = basePrice + (seed % 300);
```

### 性能优化

1. **批量插入**: 每批100家酒店使用一个事务
2. **内存优化**: 先生成所有数据,再批量写入
3. **进度显示**: 实时显示进度条和预计剩余时间
4. **错误处理**: 单批失败不影响其他批次

## 常见问题

### Q: 生成10000家酒店需要多长时间?

A: 约1分钟,具体取决于机器性能和数据库配置。

### Q: 可以修改生成的酒店数量吗?

A: 可以,编辑 `src/seeds/scripts/generate-hotels.ts` 文件中的 `TOTAL_HOTELS` 常量。

### Q: 生成的数据会覆盖现有数据吗?

A: 不会,脚本会检查现有数据量,只生成缺少的部分。如需重新生成,请先运行 `npm run clear-hotels`。

### Q: 为什么要生成这么多数据?

A: 
1. 测试大数据量下的性能
2. 确保筛选功能在各种条件下都能正常工作
3. 测试分页加载功能
4. 模拟真实生产环境

### Q: 数据库空间占用多少?

A: 10000家酒店约占用:
- PostgreSQL: ~50-100 MB
- SQLite: ~30-50 MB
