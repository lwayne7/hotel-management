# 种子数据优化总结

## 优化目标
1. 对齐前端查询页、列表页所有可筛选的项
2. 保证数据分布合理，避免某个城市只有一种星级等不合理情况
3. 保证每张酒店图片和房型图片都不一样
4. 确保数据人性化和合理

## 优化内容

### 1. 常量配置优化 (`config/constants.ts`)

#### 新增前端筛选项常量
- `HOT_FILTER_TAGS`: 前端热门筛选标签（9个）
- `HOTEL_FEATURES`: 前端酒店特色标签（6个）
- `ROOM_FEATURES`: 前端客房特色标签（6个）
- `FACILITY_SERVICES`: 前端设施服务标签（9个）
- `FRONTEND_BRANDS`: 前端品牌列表（13个）

#### 新增设施分组
- `metro`: 地铁交通设施分组，包含"近地铁"相关标签

### 2. 酒店生成器优化 (`generators/hotel-generator.ts`)

#### 核心改进

**a) 星级分布优化**
- **问题**: 原代码使用 `(index % 5) + 1`，导致每个城市只有一种星级
- **解决**: 
  - 为每个城市预先分配1-5星级的酒店
  - 使用基于种子的随机数打乱顺序，确保结果可重复
  - 每个城市都有各种星级的酒店

**b) 设施标签生成优化**
- **问题**: 原代码使用 `index % 6`，标签分布不够均匀
- **解决**:
  - 使用 `cityIndex * 7 + seed` 确保不同城市有不同的标签分布
  - 每个城市都有各种筛选标签（亲子、豪华、免费停车场、含早餐、健身房、近地铁、游泳池）
  - 根据星级智能添加相关设施

**c) 房型生成优化**
- **问题**: 房型选择随机，可能缺少前端筛选项需要的房型
- **解决**:
  - 如果酒店有"亲子"标签，确保至少有一个家庭房或亲子主题房
  - 确保至少有一个大床房或双床房（对齐前端筛选项）
  - 使用唯一种子确保每个房型图片都不一样

**d) 品牌选择优化**
- **问题**: 品牌选择不考虑前端品牌列表
- **解决**:
  - 优先使用前端品牌列表中的品牌（如果匹配星级）
  - 确保生成的酒店品牌在前端筛选项中能找到

**e) 图片唯一性保证**
- **问题**: 图片可能重复
- **解决**:
  - 酒店图片：使用 `index * 10000 + cityIndex * 1000 + starRating * 100` 作为种子
  - 房型图片：使用 `hotelIndex * 1000 + cityIndex * 100 + roomIndex * 10 + seed` 作为种子
  - 确保每张图片都不一样

**f) 确定性随机数生成**
- 使用基于种子的伪随机数生成器（LCG算法）
- 确保相同输入产生相同输出，便于测试和调试

### 3. 精选酒店数据优化 (`data/featured-hotels.ts`)

#### 改进内容
- 使用 `generateHotelImages()` 函数生成酒店图片，确保图片唯一性
- 使用 `getRoomImageByType()` 函数生成房型图片，确保图片唯一性
- 为每个酒店和房型使用唯一的ID作为种子
- 添加"近地铁"标签到相关酒店

#### 覆盖的筛选项
- ✅ 热门筛选：双床房、大床房、含早餐、免费停车场、游泳池、健身房、亲子、豪华、近地铁
- ✅ 酒店特色：亲子、近地铁、豪华、游泳池、SPA、含早餐
- ✅ 客房特色：家庭房、套房、亲子主题房、双床房、大床房、标准间
- ✅ 设施服务：免费停车场、免费WiFi、含早餐、游泳池、健身房、SPA、中餐厅、24小时前台、近地铁
- ✅ 品牌：希尔顿、华尔道夫、全季、亚朵、威斯汀、瑞吉等

### 4. 数据分布保证

#### 城市分布
- 50个城市均匀分布
- 每个城市都有各种星级的酒店

#### 星级分布
- 每个城市都有1-5星级的酒店
- 星级分布均匀

#### 价格分布
- 根据星级智能生成价格
- 覆盖前端所有价格区间（200以下、200-350、350-450、450-550、550-900、900-1400、1400-1900、1900以上）

#### 设施标签分布
- 每个城市都有各种筛选标签
- 标签分布均匀，确保筛选功能正常

## 使用说明

### 重新生成种子数据

```bash
# 1. 清空现有数据（可选）
# 删除数据库中的酒店数据

# 2. 初始化基础数据
npm run seed

# 3. 批量生成测试酒店（10000家）
npm run generate-hotels
```

### 验证数据分布

运行生成脚本后，会输出统计信息：
- 标签分布
- 星级分布
- 价格分布

检查这些统计信息，确保分布合理。

## 注意事项

1. **图片唯一性**: 使用基于种子的随机数生成器，确保相同输入产生相同输出
2. **数据确定性**: 所有随机操作都基于种子，便于测试和调试
3. **性能优化**: 使用批量生成和事务提交，提高生成速度
4. **扩展性**: 代码结构支持轻松添加新的筛选项和设施标签
