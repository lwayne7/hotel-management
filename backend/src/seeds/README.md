# Seeds 模块

种子数据和测试数据生成模块，用于初始化数据库和生成大规模测试酒店数据。

## 目录结构

```
seeds/
├── config/                 # 配置模块
│   ├── database.ts        # 共享数据库连接配置
│   ├── constants.ts       # 城市、设施、房型常量（50城市、85品牌）
│   └── types.ts           # TypeScript 类型定义
├── data/                   # 数据模块
│   ├── users.ts           # 用户种子数据（3个测试账号）
│   └── featured-hotels.ts # 20家精选演示酒店
├── generators/             # 生成器模块
│   └── hotel-generator.ts # 酒店批量生成器（支持10000+）
├── images/                 # 图片模块
│   └── hotel-images.ts    # 150+ 张 Unsplash 高质量酒店图片
├── scripts/                # 执行脚本
│   ├── seed.ts            # 基础种子脚本（用户+精选酒店）
│   ├── generate-hotels.ts # 批量生成10000家酒店
│   └── update-images.ts   # 更新现有酒店图片
├── index.ts               # 模块入口，导出所有公共接口
└── README.md              # 本文件
```

## 使用方法

### 1. 初始化基础数据

```bash
npm run seed
```

创建：
- 3 个测试用户（2 商户 + 1 管理员）
- 20 家精选演示酒店

### 2. 批量生成测试酒店

```bash
npm run generate-hotels
```

生成 10000 家酒店，特性：
- 事务批量写入，性能优化
- 实时进度显示和耗时统计
- 支持增量生成（检测已有数据）
- 确保筛选标签和星级均匀分布（每个标签约 2000 家）

### 3. 更新酒店图片

```bash
npm run update-images
```

将数据库中的酒店图片更新为精选 Unsplash 图片。

图片使用种子算法分配，确保：
- 同一酒店不同加载时图片一致
- 不同城市的酒店有不同的图片组合
- 房型图片与房型名称匹配

## 注意事项

1. **首次运行**：必须先执行 `npm run seed` 创建用户，才能执行批量生成
2. **增量生成**：脚本会检测已有酒店数量，自动计算需要生成的数量
3. **性能优化**：使用事务批量提交，100 家酒店一个事务
4. **数据一致性**：事务确保酒店、房型、图片数据完整写入
5. **进度显示**：实时显示进度条、已用时间和预计剩余时间
